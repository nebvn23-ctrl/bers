# $BER — The mascot of bear market

Static site. No build step.

- `index.html` — the whole site (3D model and images are inside it, no assets folder needed)
- `config.js` — **edit this one**: CA, X link, buy link

GitHub: upload all files to the repository root → commit.
GitHub Pages: Settings → Pages → Branch `main` / root.
Vercel: import the repo → Framework Preset **Other** → no build command → Deploy.
